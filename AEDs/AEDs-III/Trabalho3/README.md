# Trabalho 3 — AEDs III

Resumo

- Este diretório contém o material do Trabalho 3 da disciplina de Algoritmos e Estruturas de Dados III (AEDs-III): enunciado, código-fonte, gerador de casos de teste e script para execução dos testes.

Estrutura

- `AEDs/AEDs-III/Trabalho3/descricao (1).pdf` — Enunciado do trabalho.
- `AEDs/AEDs-III/Trabalho3/codigo/` — Código-fonte do(s) exercício(s).
- `AEDs/AEDs-III/Trabalho3/gerador/` — Ferramentas para gerar casos de teste.
- `AEDs/AEDs-III/Trabalho3/run_teste.bat` — Script Windows para executar testes automaticamente.

Como executar (Windows)

1. Abra um terminal (PowerShell) na pasta do trabalho:

```powershell
cd "AEDs/AEDs-III/Trabalho3"
```

2. Execute o script de testes:

```powershell
.\run_teste.bat
```
